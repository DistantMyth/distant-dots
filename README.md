# distant-dots
dotfiles along with a script to add widgets changing your end4 experience.

## Changes Made
### Desktop environment
- **Base Setup:** Installed end4-dotfiles on hyprland with customized shortcuts.
- **Custom made desktop widgets:** Material 3 themed quickshell widgets, manageable by default settings widget on desktop which include:
	- A customizable audio visualizer
	- Clock and weather (inbuilt)
	- Github and codeforces tracker
	- System monitoring
- **Systemwide blur:** Added systemwide blur in hyprland (except for x11 based applications since they have some issue with the borders)

### Application Specific Changes
- **Kitty Terminal:** Used fastfetch and tide prompt, added transparency and blur (also shows github and codeforces stats).
- **Spotify:** Applied custom themes and extensions to spotify desktop with spicetify, adding blur and features like better fullscreen and better lyrics and adblocking capabilities.
- **Zen Browser:** Customized zen-browser with sine, applied nebula translucent theme and custom color gradient also with uBlock Origin.


### System level changes
- **Applied custom made sddm-theme**
- **Applied custom made grub theme**
